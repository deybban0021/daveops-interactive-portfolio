# DESIGN.md

## Brand Positioning

DaveOps is the premium personal portfolio of Dave Van Larcena: a GoHighLevel specialist, automation builder, and AI workflow implementer.

The portfolio should communicate that Dave designs and builds:

- GoHighLevel systems
- AI automations
- CRM dashboards
- backend workflow systems
- n8n automations
- webhook flows
- custom frontend/backend logic

This site is portfolio-first. It should present Dave as a sharp, trustworthy technical operator who builds connected systems for real client operations. It should never read like a software company homepage, workflow-builder SaaS, or product dashboard.

Core positioning:

- Premium personal portfolio
- Dark-mode technical aesthetic
- Automation and AI focused
- Modern and cinematic, but clean
- Confident and design-aware
- Client outcomes over product features

## Visual Identity

The visual system should feel precise, restrained, and premium.

Primary palette:

- Background: deep navy / near-black / blue-black
- Surface: charcoal / dark glass / blue-black panels
- Accent: cyan / electric blue
- Text: off-white
- Secondary text: muted blue-gray
- Borders: subtle blue-gray with occasional cyan edge glow

Atmosphere rules:

- Use subtle cyan glow, not loud neon everywhere
- Use minimal gradients with soft transitions
- Keep contrast refined and intentional
- Maintain dark-mode elegance instead of flashy “tech demo” styling

Avoid:

- Gold-heavy styling
- Brown or muddy tones
- Flat gray-on-gray monotony
- Rainbow accents
- Overly purple visual bias unless absolutely necessary and very restrained

## Typography Direction

Typography should be one of the strongest parts of the portfolio.

Rules:

- Big confident hero typography
- Clean sans-serif
- Strong, readable headline
- Spacious line-height
- Sharp hierarchy using scale, spacing, and weight
- Bold but controlled composition

Hero typography should feel:

- Powerful
- Editorial
- Spacious
- Modern
- Premium

Avoid:

- Cramped stacked text
- Tiny unreadable supporting text
- Over-decorative fonts
- Weak hierarchy
- Dense blocks of copy with no breathing room

## Layout Principles

Overall layout should feel spacious, deliberate, and story-led.

Principles:

- Spacious composition
- Strong hero hierarchy
- Portfolio content comes first
- 3D is supporting artwork only
- Content should never feel trapped inside a tiny UI box
- Sections should flow like a designed narrative, not a dashboard

Hero and section rules:

- Avoid small trapped-card hero layouts unless heavily justified by composition
- Avoid product-dashboard layouts
- Avoid right-heavy “mock app beside copy” patterns
- Use negative space confidently
- Let typography lead first, then supporting visual atmosphere, then detail

Approved storytelling structure:

1. Hero
2. Services
3. Featured Work / Case Studies
4. Tools & Stack
5. Process
6. Contact CTA

## Hero Direction

## 3D Art Direction

The 3D scene is a hero enhancement, not the thing being sold.

Desired feel:

- Abstract connected-node landscape
- Sculptural
- Atmospheric
- Premium
- Technical
- Calm and cinematic

Approved visual ingredients:

- Dark glass panels
- Small system blocks
- Automation-node shapes
- Thin cyan glowing wires
- Soft glow
- Atmospheric depth
- Subtle parallax
- Slow looping motion

Important rules:

- Not every node needs readable text
- Nodes can behave like abstract landmarks in a digital landscape
- The 3D should feel like a visual metaphor for connected systems and automation
- It should sit behind typography the way landscape art sits behind editorial type

Avoid:

- Giant readable workflow cards
- Product UI clutter
- Giant boards/canvases
- Literal workflow-builder layouts
- A row of cards on the right
- Chunky old-game 3D blocks
- n8n-clone composition
- Dashboard-demo behavior

## Components

Every component should follow restrained dark-tech polish.

### Hero Labels

- Small uppercase label
- Generous letter spacing
- Cyan accent
- Quiet but precise

### Buttons

- Primary button: clean, confident, high-contrast
- Secondary button: subtle, understated, refined
- Rounded but not toy-like
- Smooth hover states
- No loud gradients or gimmicky shine effects

### Chips

- Small rounded pills
- Thin borders
- Cyan/blue edge treatment
- Clean spacing
- Should feel crisp and intentional

### Cards

- Dark glass / charcoal panels
- Thin borders
- Soft shadows
- Subtle cyan glow
- Clean spacing
- Premium without being flashy

### Case Study Cards

- Clear hierarchy
- Project title first
- Supporting context concise
- Strong contrast
- Spacious padding

### Section Headings

- Strong and clean
- Distinct from body copy
- Clear visual rhythm between sections

### Service Cards

- Focus on outcome and capability
- Avoid dashboard aesthetics
- Use calm structure and consistent spacing

### Process Steps

- Sequential and readable
- Light technical feel
- More editorial than app-like

## Motion Rules

Motion should support content, not distract from it.

Allowed motion:

- Smooth subtle motion only
- Soft parallax
- Fade / scale / slide transitions
- Subtle glow pulses
- Gentle reveal timing

Avoid:

- Orbiting
- Full-scene rotation
- Chaotic 3D camera movement
- Aggressive bouncing
- Overactive particle behavior
- Over-explained animation

Motion should feel:

- Controlled
- Cinematic
- Refined
- Supportive of hierarchy

## Do / Don’t Rules

### Do

- Build a premium personal portfolio
- Make typography powerful
- Keep the composition spacious
- Use 3D as atmospheric hero artwork
- Make the site feel technical and trustworthy
- Keep portfolio content readable
- Use restrained dark-mode polish
- Prioritize hierarchy and calm precision

### Don’t

- Do not make it look like a workflow-builder SaaS
- Do not make it look like n8n
- Do not make it look like a product dashboard
- Do not make the 3D the main product
- Do not use a giant right-side workflow panel
- Do not trap the hero inside a small card
- Do not use chunky old-game 3D blocks
- Do not copy another brand exactly
- Do not let product-demo aesthetics overpower portfolio storytelling

## Direction Summary

When in doubt, favor:

- portfolio-first over product-first
- typography-first over UI-first
- atmospheric 3D over literal workflow UI
- calm precision over flashy complexity
- cinematic composition over app-demo composition

This portfolio should feel like DaveOps builds systems for clients, not like DaveOps is selling a workflow builder.
